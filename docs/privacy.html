隐私政策

更新日期：2026年11月7日
生效日期：2026年11月7日

感谢您使用「盈记」（以下简称「本应用」）。

本应用尊重并保护所有用户的个人隐私。本隐私政策旨在向您说明本应用如何收集、使用和保护您的信息。

一、我们收集的信息

本应用是一款本地工具软件，所有数据均存储在您的设备本地。我们不会收集、上传或分享您的任何个人信息，包括但不限于：

  • 不收集您的姓名、手机号、邮箱等个人身份信息
  • 不收集您的设备信息、位置信息
  • 不收集您录入的商品数据、利润数据

二、权限使用说明

本应用会申请以下权限，仅用于实现核心功能：

  • 相机权限：用于拍照识别商品信息（OCR文字识别），仅在您主动使用「截图识别」功能时请求
  • 文件与相册访问权限：用于从相册选择截图识别商品信息（OCR文字识别）、选择导入文件及导出数据备份，仅在您主动使用相关功能时请求
  • 麦克风权限：用于语音搜索商品，仅在您主动点击搜索框旁的麦克风图标后录音；录音与识别全部在您的设备本地完成，不会上传、不会保存
  • 剪切板读取：用于快速粘贴商品信息。本应用启动或回到前台时会读取剪切板，识别到商品信息时自动跳转录入页并填入，之后会清空剪切板以避免重复导入；iOS 系统可能弹出「允许粘贴」提示，整个过程在设备本地完成

以上权限均不会用于收集个人信息，关闭权限不影响其他功能使用。

三、信息存储与安全

您录入的所有商品数据和利润计算记录均存储于您的设备本地文件中。本应用不提供云端同步功能，数据不会上传至任何服务器。建议您定期通过「导出分享」功能备份数据。

四、第三方SDK

本应用使用了以下第三方SDK：

  • Google ML Kit：用于图片文字识别（OCR），所有识别过程在设备本地完成，不会上传图片
  • sherpa-onnx：用于语音识别，识别模型随应用安装包一起分发，识别过程完全在设备本地完成，不会上传录音。该组件不包含任何联网功能
  • Apple StoreKit：用于处理 Pro 会员订阅支付，订阅信息和支付通过 Apple 处理，我们不会获取您的支付信息

五、Pro 会员订阅

本应用提供 Pro 会员自动续期订阅服务（¥4.80/月、¥39.00/年），用于解锁截图识别无限使用权限。免费版每日提供 3 张截图识别额度，Pro 会员不限次数。

  • 订阅费用通过您的 Apple ID 账户支付
  • 订阅会在到期前 24 小时内自动续费
  • 您可以在 iPhone 的「设置 → Apple ID → 订阅」中管理或取消订阅
  • 取消订阅后，当前订阅周期内仍可享受 Pro 会员权益
  • 订阅状态仅保存在您的设备本地，我们不会收集或存储您的订阅信息

六、隐私政策更新

本隐私政策可能会不定期更新。更新后的政策将在本应用内展示，继续使用即表示您同意更新后的政策。

八、儿童隐私

本应用不面向14周岁以下的儿童。我们不会故意收集儿童的个人信息。如果监护人发现儿童向我们提供了个人信息，请通过上述邮箱联系我们，我们将立即删除相关数据。

九、数据删除

您的所有数据仅存储在设备本地。您可以通过以下方式完全删除数据：

  • 在应用内逐条删除商品记录和利润记录
  • 卸载本应用即可彻底删除所有本地数据
